# Raufbold3b's Scratch Archive (RSA)

The RSA Collection contains **15** really old games, programmed in Scratch/Penguinmod by HoppiTex from ~1018 until ~2025.
Some of the Projects have been released on Scratch already, while some other projects are unfinished and have not been public before.
